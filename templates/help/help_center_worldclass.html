Getting started

AssetPro limits records and actions according to your company, branch and role. If an operation is unavailable, first confirm that you are working in the correct branch.

Recommended first steps

  1. Confirm the active company and branch in the workspace switcher.
  2. Use global search or the Assets page to locate a record.
  3. Open the asset detail before starting a transfer, maintenance or disposal request.
  4. Review system messages after every submission.

Roles

  • Users view permitted assets and submit operational requests.
  • Managers oversee assigned branches and perform authorized reviews.
  • Administrators manage organization settings, access and cross-branch controls.

Asset records and QR scanning

Search by asset tag, serial number, category or other available fields. The asset detail is the source for current status, assignment and lifecycle actions.

  • Use filters to narrow large result sets and clear them when switching tasks.
  • Scan a QR code only from the built-in scanner or a trusted camera application.
  • Verify the displayed identifier before editing, transferring or requesting maintenance.
  • Use the import template from the Resources page for supported bulk registration.

Transfers and approvals

Lifecycle-sensitive changes may require a separate reviewer. A requester cannot approve their own request where separation of duties applies.

  1. Submit complete operational context and a clear justification.
  2. Monitor the request status instead of resubmitting duplicates.
  3. Reviewers should inspect the target asset, branch and requester before deciding.
  4. Use rejection notes to state what must be corrected.

Transfers remain pending until every required receiver or administrator decision is recorded.

Maintenance workflow

Maintenance can be scheduled only for eligible assets with maintenance tracking enabled.

  1. Open Maintenance and choose an eligible asset.
  2. Select a future date and an optional supervisor.
  3. Start the record when work begins.
  4. Record an outcome and cost when completing work, or provide a reason when cancelling.

Completed and cancelled records remain part of the audit history.

Reports, settings and access

Reports include only information available to your current role and branch scope. Administrators can manage organization configuration and user access from Settings.

  • Apply report filters before downloading large result sets.
  • Do not share exported data outside authorized business channels.
  • Contact an administrator if a legitimate branch or action is missing.
