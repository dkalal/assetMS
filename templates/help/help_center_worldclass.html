Getting Started

System Overview

The Enterprise Asset Management System is a comprehensive platform designed to help organizations track, manage, and maintain their assets throughout their lifecycle. Built with multi-tenancy support, it allows multiple companies and branches to operate independently while maintaining centralized oversight.

Key Features

Complete Asset Tracking

Track assets from acquisition to disposal with full lifecycle management.

QR Code Integration

Quick asset identification and tracking using QR codes.

Advanced Analytics

Comprehensive reports and real-time analytics dashboards.

Role-Based Access

Granular permissions based on user roles and responsibilities.

User Roles & Permissions

The system supports three main user roles, each with specific permissions and capabilities:

Administrator
  • Full system access
  • User management
  • Company & branch setup
  • System configuration
  • All asset operations
Manager
  • Branch-level access
  • Approve requests
  • Asset management
  • Reports & analytics
  • Team oversight
User
  • View assets
  • Submit requests
  • Scan QR codes
  • Basic reports
  • Profile management

Your First Steps

  1. Complete Your Profile: Update your profile information and preferences
  2. Explore the Dashboard: Familiarize yourself with the main dashboard and navigation
  3. View Assets: Browse the asset list to see what's already in the system
  4. Try Scanning: Use the QR scanner to identify an asset
  5. Check Help Resources: Review relevant documentation for your role

Asset Management

Adding Assets

There are multiple ways to add assets to the system:

1. Single Asset Registration

Use the asset registration wizard for adding individual assets with complete details:

  1. Navigate to Assets → Register New Asset
  2. Select the asset category
  3. Fill in required fields (name, serial number, etc.)
  4. Upload asset images (optional)
  5. Assign to user or branch
  6. Save the asset

2. Bulk Import

For importing multiple assets at once:

  1. Download the import template
  2. Fill in asset data in Excel/CSV
  3. Upload the file
  4. Review and validate
  5. Complete the import

3. QR Scanner Registration

Quickly register assets while scanning:

  1. Use the QR scanner
  2. If asset not found, select "Register New"
  3. Fill in quick registration form
  4. Asset is created and linked to QR code

Approval System

Understanding Approvals

The approval system ensures proper oversight and control over critical asset operations. It supports various approval workflows:

When Approvals Are Required

  • Asset Creation: Regular users must submit requests for manager approval
  • Asset Disposal: Requests to retire or delete assets require approval
  • Asset Transfers: Some transfer operations may require approval
  • Custom Workflows: Organization-specific approval processes

Approval Roles

  • Requester (User): Submits approval requests
  • Approver (Manager): Reviews and approves/rejects branch requests
  • Admin: Can approve any request company-wide

Creating Approval Requests

To create an approval request:

  1. Navigate to Approval Center
  2. Click "Create New Request"
  3. Select request type
  4. Fill in details and justification
  5. Set priority and deadline
  6. Submit for review

Approving Requests (Managers & Admins)

To review and approve requests:

  1. Go to Approval Center
  2. View "Pending Approvals" tab
  3. Click "Review Details" on any request
  4. Review the request information
  5. Add comments (optional)
  6. Click "Approve" or "Reject"
Pro Tip: Use the priority badges to identify urgent requests that need immediate attention.
