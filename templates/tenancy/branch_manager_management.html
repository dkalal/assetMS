How It Works
  • Branch Manager: The person responsible for managing a branch's assets and staff.
  • Assignment: Select a branch and manager above, then click "Assign Manager".
  • Removal: Select "No Manager" from the dropdown to remove the current manager.
  • Notifications: Managers receive alerts when assigned or removed from branches.
  • Audit Trail: All changes are logged for compliance and security.
  • Permissions: Only users with 'manager' or 'admin' roles can be assigned as branch managers.
