Asset Management

  1. Navigate to Assets in the sidebar
  2. Click Register New Asset button
  3. Select the appropriate category for your asset
  4. Fill in the required fields (marked with *)
  5. Add any custom fields specific to your asset type
  6. Upload images or documents if needed
  7. Click Save Asset to complete registration
Tip: Use descriptive names and include serial numbers for better tracking.

Use the advanced filtering options on the Assets page:

  • Category: Filter by asset type (e.g., Electronics, Furniture)
  • Status: View Active, Maintenance, or Retired assets
  • Location: Search by asset location
  • Search: Find assets by name, model, or description
  • Custom Fields: Filter by any custom field values
Pro Tip: Use the tab navigation to quickly switch between different asset views.

  1. Click Bulk Import from the Assets page
  2. Select the asset category
  3. Download the Excel template
  4. Fill in the template with your asset data
  5. Upload the completed template
  6. Review the preview and confirm import
Important: Ensure all required fields are filled and data formats are correct.

QR Code Scanning

Using the QR Scanner
  1. Navigate to Scan in the sidebar
  2. Click Start Scanning
  3. Point your camera at the asset's QR code
  4. View asset details instantly
Manual Lookup
  1. Enter the asset code or ID manually
  2. Click Lookup
  3. View complete asset information
Note: QR codes are automatically generated for all assets and can be downloaded from the asset detail page.

Reports & Analytics

Generate comprehensive reports for asset analysis, compliance, and decision-making:

  • Asset Summary: Overview of all assets by category and status
  • Depreciation Reports: Track asset value over time
  • Maintenance Reports: Monitor maintenance schedules and costs
  • Export Options: Download reports in Excel, CSV, or PDF formats
Available Formats: Excel (.xlsx), CSV (.csv), PDF (.pdf)

Audit Trail

The system maintains a complete audit trail of all asset-related activities:

  • Asset Creation: Track when and by whom assets were added
  • Status Changes: Monitor asset status updates
  • Assignments: Track asset transfers between users
  • Maintenance: Log all maintenance activities
  • Advanced Filtering: Filter logs by user, action, date range, and more
